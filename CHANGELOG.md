# Changelog

## Unreleased

## 0.1.2

- The keys that approve an item and open it in Plane, A and O to begin with, can be
  changed or removed in Settings → General.

## 0.1.1

- While items wait, the menu bar icon and count take a colour, blue to begin with. Choose
  another, or the menu bar's own, in Settings → General.

## 0.1.0

First version.

- Menu bar count of Plane work items in the watched phases.
- A menu with one card per watched phase, in Plane's order, items grouped by project.
- A row opens out to the item's description, priority, labels and module.
- Approve moves an item to the next state in its project's order, at once, with Undo for
  a few seconds; Open in Plane goes to its page.
- Keyboard navigation and a system-wide shortcut.
- A banner when an item enters a watched phase.
- Settings for the API key (kept in the Keychain), workspace, projects, phases, refresh
  interval, notifications and launch at login.
